ZOMBIE SQUAD – DYNAMIC SHOP ASSET PACK

All balances, quantities, prices and button labels are intentionally excluded from the artwork.
Add them as separate runtime text objects (Unity TextMeshPro recommended):
- coinBalance: 5980
- diamondBalance: 50
- productAmount: 1000 / 5000 / 20000 / 50000
- productPrice: ₹80 / ₹200 / ₹1000 / ₹2000
- shopTitle and buttonLabel

Suggested hierarchy:
Canvas > ShopScreen > Header (BackButton, ShopTitle, CoinBar, DiamondBar)
Canvas > ShopScreen > ProductGrid > ProductCard x4
Each ProductCard: CardFrame, AmountLabel, ProductArt, PurchaseButton, PriceLabel.

PNG files are cropped raster components from the generated asset sheet; some may retain a small amount of surrounding dark background/glow. SVG files are editable vector primitives. Soldier, logo and item artwork are raster, not 3D source models.
